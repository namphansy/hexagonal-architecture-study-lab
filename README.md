# Order Service Hexagonal Architecture Lab

This repository is a Spring Boot skeleton for the lab in
`docs/hexagonal-architecture-springboot-lab.md`.

The project intentionally contains only the architectural frame:

- domain model package without Spring annotations
- inbound and outbound application ports
- application service placeholders
- inbound REST adapter placeholder
- outbound persistence, customer, inventory, and messaging adapter placeholders
- Spring Boot entry point and configuration package

Business rules and exercise implementations are intentionally left out.
